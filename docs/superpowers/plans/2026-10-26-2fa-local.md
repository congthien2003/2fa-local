# 2FA Local Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for Native execution or superpowers:subagent-driven-development if the user chooses delegated execution. Steps use checkbox syntax. User instructions override skill defaults: no automatic build/test/lint/verification, no commits, no implementation until this plan is approved.

**Goal:** Web lưu từng tài khoản test trong localStorage, hiện đầy đủ key và mã TOTP để copy nhanh.

**Architecture:** Một trang HTML, TypeScript quản lý DOM và trạng thái. TOTP chạy bằng Web Crypto trong browser; storage tách khỏi UI. Vite xuất `dist`, Cloudflare Workers Static Assets phục vụ trực tiếp, không backend.

**Tech Stack:** HTML, CSS, TypeScript strict, Vite, native Web Crypto, npm; Vitest + jsdom chỉ làm dev dependencies cho regression tests; Wrangler cho local preview/deploy. Không có runtime dependency.

**Spec:** `docs/superpowers/specs/2026-10-26-2fa-local-design.md` (đã duyệt).

## Global Constraints

- Nhập từng tài khoản, gồm email và key; danh sách `email | key | mã OTP`; hiện đầy đủ key.
- TOTP: Base32, HMAC-SHA1, 6 chữ số, chu kỳ 30 giây, epoch Unix.
- Form padding 16px; dòng bảng 13px dọc, 16px ngang; bám `account-list-v2.html`.
- localStorage key `2fa-local.accounts.v1`; chỉ chứa version và accounts, không lưu OTP.
- Không API, database, analytics, CDN dependency, đăng nhập hoặc mã hóa storage.
- Không import/export, QR, thêm hàng loạt, search, dark mode, PWA hoặc đồng bộ cloud.
- Không tự chạy build, test, lint, typecheck, browser verification, deploy hoặc commit. Các lệnh bên dưới chỉ để người dùng tự chạy.
- Chỉ cài dependencies sau khi duyệt plan; dùng `npm install --ignore-scripts` để tránh lifecycle scripts tự chạy kiểm tra/build. Nếu môi trường cần bước cài bổ sung, bàn giao command, không tự chạy verify.
- Đọc lại AGENTS.md nếu xuất hiện trước triển khai; giữ nguyên bản phác và mọi thay đổi ngoài phạm vi.

## Review Focus

1. Base32 có padding hoặc trailing bits sai: từ chối, không tạo secret khác ý định (Task 1).
2. Dữ liệu storage JSON hợp lệ nhưng sai schema hoặc ID trùng: khóa ghi, giữ nguyên dữ liệu (Task 2).
3. HMAC trả kết quả cũ sau sửa/xóa hoặc đổi chu kỳ: không render/copy kết quả đó (Task 3).
4. Tab khác cập nhật lúc đang sửa: nạp lại storage, hủy sửa và thông báo (Task 3).
5. Clipboard bị chặn hoặc storage hết dung lượng: báo lỗi, không báo thành công giả hoặc mất dữ liệu (Tasks 2–3).

## Task 1: Nền tảng project và TOTP

**Files:** `package.json`, `package-lock.json`, `.gitignore`, `tsconfig.json`, `vite.config.ts`, `src/totp.ts`, `tests/totp.test.ts`.

**Interfaces produced:**
- `normalizeSecret(raw: string): string`: bỏ whitespace, uppercase, validate Base32, bỏ padding khỏi dạng lưu canonical; throw lỗi có thông điệp tiếng Việt nếu không hợp lệ.
- `generateTotp(secret: string, nowMs: number): Promise<string>`: trả đúng 6 chữ số, không khoảng trắng.
- `getTimeStep(nowMs: number): { counter: number; remainingSeconds: number }`.
- `formatOtp(code: string): string`: `123456` → `123 456`.

- [x] Tạo cấu hình project thủ công, không dùng generator sinh tính năng ngoài scope. Chọn stable versions tương thích tại thời điểm triển khai từ metadata chính thức; pin exact dependencies và ghi Node engine tương thích. Đề xuất Node 22.12+ hoặc Node LTS mới hơn được các dependency hỗ trợ. Không tự đổi major sau khi đã có lockfile.
- [x] Định nghĩa scripts: `dev: vite`, `typecheck: tsc --noEmit`, `test: vitest run`, `build: vite build`, `preview: vite preview`, `worker:dev: wrangler dev`, `deploy: wrangler deploy`. Không tạo pre/post scripts chạy verify hoặc build ngầm.
- [x] Cài dev dependencies với `npm install --save-dev --save-exact --ignore-scripts vite typescript vitest jsdom wrangler` để tạo lockfile. Không chạy các script trên.
- [x] Viết regression tests trước implementation. Với secret ASCII `12345678901234567890` được biểu diễn Base32 là `GEZDGNBVGY3TQOJQGEZDGNBVGY3TQOJQ`: `generateTotp(secret, 59000)` phải bằng `287082`; tại `1111111109000` bằng `081804`; tại `1234567890000` bằng `005924`.
- [x] Thêm assertions: `getTimeStep(29999)` trả counter 0/remaining 1; `getTimeStep(30000)` trả counter 1/remaining 30; mã không đổi trong cùng counter. `normalizeSecret(' my====== ')` bằng `MY`; `MY` và `MY======` decode cùng bytes. Từ chối `MZ` (trailing bits khác 0), `MY=`, ký tự `0/1/8/9`, secret rỗng và độ dài không decode được.
- [x] Implement Base32 theo RFC 4648, HMAC-SHA1 bằng `crypto.subtle`, counter unsigned 8-byte big-endian và dynamic truncation theo RFC 6238; modulo 1_000_000, padStart 6. Không tạo thuật toán crypto riêng hoặc request ngoài browser.
- [x] Ghi nhận các test chưa chạy; bàn giao user `npm run test -- tests/totp.test.ts` và `npm run typecheck`.

## Task 2: Tài khoản và storage có bảo toàn dữ liệu

**Files:** `src/accounts.ts`, `tests/accounts.test.ts`.

**Consumes:** `normalizeSecret(raw)` từ Task 1.

**Interfaces produced:**
- `type Account = { id: string; email: string; secret: string }`.
- `type AccountInput = { email: string; secret: string }`.
- `type LoadResult = { ok: true; accounts: Account[] } | { ok: false; message: string }`.
- `loadAccounts(storage: Pick<Storage, 'getItem'>): LoadResult`.
- `saveAccounts(storage: Pick<Storage, 'setItem'>, accounts: readonly Account[]): void`: throw khi ghi lỗi, không tự mutate UI.
- `validateAccount(input: AccountInput, accounts: readonly Account[], editingId?: string): AccountInput`: trả input chuẩn hóa hoặc throw lỗi field/duplicate. Email validation sử dụng HTML email input validity trong browser, không tự tạo regex quá chặt.
- `addAccount(accounts: readonly Account[], input: AccountInput, id: string): Account[]`.
- `updateAccount(accounts: readonly Account[], id: string, input: AccountInput): Account[]` và `removeAccount(accounts: readonly Account[], id: string): Account[]`. ID không tồn tại phải báo lỗi, không tạo bản ghi mới ngầm.

- [x] Viết tests: storage vắng key → danh sách rỗng; reload giữ thứ tự và ID; payload lưu `{ version: 1, accounts }`, không có OTP; missing fields, JSON hỏng, version lạ, ID trùng và secret lỗi → `ok: false`, không gọi setItem.
- [x] Viết tests: trim email; cùng email khác secret được phép; email khác hoa/thường và cùng secret normalized bị chặn; sửa chính tài khoản đó hợp lệ, sửa thành bản ghi trùng bị chặn; thêm cuối/sửa tại chỗ/xóa đúng ID.
- [x] Implement các hàm pure CRUD và wrapper storage; validate toàn bộ payload trước khi trả accounts, không ghi lại khi load và không log secret.
- [x] Thêm case getItem ném SecurityError và setItem ném QuotaExceededError. Caller phải nhận lỗi để giữ dữ liệu đang hiển thị; không có reset storage tự động.
- [x] Bàn giao user `npm run test -- tests/accounts.test.ts`; không đánh dấu tests pass khi chưa có kết quả.

## Task 3: Giao diện và luồng sử dụng hoàn chỉnh

**Files:** `index.html`, `src/main.ts`, `src/app.ts`, `src/styles.css`, `tests/app.test.ts`.

**Consumes:** Interfaces Task 1–2.

**Produces:** `mountApp(root: HTMLElement): () => void` trong `src/app.ts`; hàm trả về cleanup cho timer/listeners. `src/main.ts` gọi một lần khi khởi tạo và cleanup khi Vite HMR dispose.

- [x] Viết regression tests với jsdom, fake clock và Web Crypto mock có deferred promises: add/reload/edit/cancel/delete; confirm false giữ tài khoản; dữ liệu text chứa HTML không được tạo markup; empty state và lỗi validation đúng vùng.
- [x] Viết tests storage failure: sau lỗi setItem, danh sách và form hiện tại vẫn giữ; schema lỗi lúc load chặn submit và không ghi; storage event trong chế độ sửa hủy sửa và tải lại; lỗi storage từ tab khác cũng khóa ghi.
- [x] Tạo root HTML và CSS từ bản phác v2. Không đưa demo data, thông báo mockup hoặc server companion vào sản phẩm. Dùng label liên kết input, nút keyboard-accessible, focus visible và `role=status`/error text; không live-announce timer mỗi giây.
- [x] Implement state gồm accounts, editingId, readOnlyError và generation revision. Trước khi mutate, đọc lại storage để hạn chế dùng snapshot cũ; bắt lỗi và chỉ cập nhật state sau khi save thành công. Nếu ID đang sửa đã biến mất hoặc storage lỗi thì hủy thao tác và thông báo. Giữ cơ chế last-write-wins đã chốt, không thêm transaction lock.
- [x] Render bằng DOM/textContent cho dữ liệu người dùng. Form validate email theo HTML validity sau trim và validate secret qua Task 2. Dùng `crypto.randomUUID()` cho tài khoản mới. Sửa có lưu/hủy; xóa dùng confirm, xóa dòng đang sửa thì hủy sửa.
- [x] Timer đọc Date.now khoảng 250ms, chỉ cập nhật text giây khi cần; sinh lại OTP khi counter hoặc accounts đổi. `focus` và `visibilitychange` làm refresh ngay. Mỗi tác vụ bất đồng bộ kiểm tra revision, ID/secret và counter trước khi render; quá hạn thì bỏ kết quả, refresh lại. Không dựng lại toàn bộ form mỗi tick.
- [x] Clipboard tính mã cho counter hiện tại tại thời điểm bấm, kiểm tra lại counter/revision sau await rồi mới gọi writeText; nếu counter đổi thì tính lại trước khi write. Chỉ báo thành công sau write resolve; không copy cache đang hết hạn. Nếu tài khoản bị sửa/xóa thì hủy copy cũ. Browser API không hỗ trợ thì báo lỗi dễ hiểu.
- [x] Thêm tests: promise HMAC cũ resolve sau edit/delete không khôi phục mã cũ; clock nhảy và focus/visibility refresh; click copy tại ranh giới chu kỳ dùng mã mới; clipboard reject không báo thành công. Không assert cứng kết quả timestamp từ máy thật.
- [x] Responsive form xếp dọc ở 720px, bảng overflow-x; giữ toàn bộ key. Thiết lập thông báo OTP đang tải/lỗi, không dùng `000000` làm placeholder.
- [x] Bàn giao user `npm run test -- tests/app.test.ts` và checklist UI bên dưới; không tự mở browser để verify.
